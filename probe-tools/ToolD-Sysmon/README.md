# ToolD-Sysmon

Sysinternals Sysmon(カーネルミニフィルタドライバー)を使った、ファイル作成/コピー・完全削除の
比較用参考記録。前段の調査(詳細は[doc/Sysmon/Sysmon.md](../../doc/Sysmon/Sysmon.md))で整理済みの
config・スクリプトをそのまま同梱している。

## 仕組み

Sysmonはカーネルにミニフィルタドライバーを常駐させ、`config.xml` で指定したルールに合致する
イベント(本設定では `FileCreate`=ID11、`FileDelete`=ID23)だけをイベントログ
(`アプリケーションとサービスログ → Microsoft → Windows → Sysmon → Operational`)に記録する常駐サービス。
ETW/FileSystemWatcherとは独立した第三の取得経路であり、**ユーザー名を直接記録する**(Security監査と
違い、追加の突合作業なしで得られる)のが特徴。

同梱の `getLog.ps1` は、Sysmonの生イベントログを読み込み、ゴミ箱移動(`$Recycle.Bin`)された際に
生成される管理用バイナリ(`$I`ファイル)を解析して「元のファイルパス」を復元し、
`日時/イベント種別/操作ユーザー/操作プログラム/対象パス` の形に整形して表示するスクリプト。

### できること / できないこと(実機検証済み、詳細は上記doc参照)

| 操作 | 検知 |
|---|---|
| 新規作成・他フォルダからのコピー | ○ |
| 通常削除(ゴミ箱移動、元パス復元込み) | ○ |
| 完全削除(Shift+Delete等) | ○ |
| 同一ボリューム内のムーブ | ✕(ファイル実体の作成・削除を伴わないため) |
| リネーム | ✕(同上。Sysmonにはファイル用のリネーム専用イベントが存在しない) |
| 上書き保存(アプリ依存) | △〜✕(一時ファイル→リネーム置換方式の場合は検知漏れ) |

## 使い方

これはビルドではなく**インストール**です。管理者権限のPowerShellで:

```powershell
.\Sysmon64.exe -accepteula -i .\config.xml
```

ログの確認は同梱の `getLog.ps1` を管理者PowerShellで実行するか、イベントビューアーで直接
`Microsoft-Windows-Sysmon/Operational` ログを見る。

アンインストールする場合:

```powershell
.\Sysmon64.exe -u
```

## 設定ファイル(`config.xml`)について

同梱の `config.xml` は `D:\tmp\` 配下と全ドライブの `$Recycle.Bin` に絞る設定になっている
(前段調査での検証環境に合わせたもの)。評価対象のパスが異なる場合は、`config.xml` 内の
`D:\tmp\` を対象パスに書き換えてから `-i` でインストールすること。設定を変更して再適用する場合は
`-c` オプションで反映できる(`.\Sysmon64.exe -c .\config.xml`)。

## 記録されるログの内容

`getLog.ps1` 実行時の整形出力例:

```
日時(JST)            イベント               操作ユーザー        操作プログラム 対象ファイル/パス
---------            --------               ------------        -------------- -----------------
2026/07/11 17:35:52  完全削除(Shift+Del)    WIN-DESK-2022\s0911 Explorer.EXE   D:\tmp\del-absolute.txt
2026/07/11 17:35:51  通常削除(ゴミ箱移動)   WIN-DESK-2022\s0911 Explorer.EXE   D:\tmp\del-normal.txt ➔ (ゴミ箱へ)
2026/07/11 17:35:48  作成/コピー            WIN-DESK-2022\s0911 Explorer.EXE   D:\tmp\del-normal.txt
```

生のイベントログ(整形前)には、上記に加えてプロセスID・実行ファイルのハッシュ・イメージパス等、
Sysmon標準のフィールドがすべて含まれる(イベントビューアーで個別イベントのXMLビューを見ると確認できる)。
